Política de Privacidade

AI-Assistente · última atualização: 11 de novembro de 2026

O AI-Assistente é um aplicativo pessoal para macOS, usado exclusivamente pelo seu desenvolvedor com as próprias contas Google. Esta política descreve quais dados ele acessa e como são tratados.

1. Dados acessados

  • Google Calendar: leitura dos eventos e criação ou exclusão de eventos quando o usuário pede.
  • Google Tasks: leitura, criação e conclusão de tarefas quando o usuário pede.
  • Endereço de e-mail da conta Google: apenas para identificar qual conta está conectada.

2. Como os dados são usados

Os dados são usados somente para responder aos pedidos do próprio usuário, como informar a agenda do dia, registrar uma tarefa ou criar um compromisso. Não são usados para publicidade, perfilamento ou qualquer outra finalidade.

3. Armazenamento

Os tokens de acesso e as preferências ficam armazenados apenas no computador do usuário. O AI-Assistente não possui servidor próprio e não mantém cópia dos dados da agenda ou das tarefas fora desse computador.

4. Serviços de terceiros

Para entender os pedidos e formular respostas, o texto do pedido e os dados necessários para respondê-lo (por exemplo, títulos e horários de eventos) são enviados à API Gemini, do Google. A previsão do tempo é obtida no serviço Open-Meteo, que recebe apenas o nome da cidade.

5. Compartilhamento

Os dados não são vendidos, transferidos ou compartilhados com terceiros, exceto o processamento descrito no item 4.

6. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google pelo AI-Assistente seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao desconectar uma conta no aplicativo, o token correspondente é apagado do computador.
